# 🏦 Bank Payroll Management System

## 📌 Project Overview
The **Bank Payroll Management System** is a console-based Python project designed to manage employee information and salary records efficiently. It allows administrators to add, view, search, and delete employee records, calculate salaries, and generate salary slips.

This project demonstrates the practical implementation of Python programming concepts.

## 🎯 Project Objectives
- Manage employee information.
- Calculate employee net salaries.
- Maintain bonus and deduction records.
- Generate employee salary slips.
- Search and delete employee records.

## ✨ Features
- **Add Employee:** Enter employee details.
- **View Employees:** Display all employee records.
- **Search Employee:** Find employees using Employee ID.
- **Salary Calculation:** Calculate net salary automatically.
- **Generate Salary Slip:** Display employee salary details.
- **Delete Employee:** Remove employee records.
- **Interactive Menu:** Easy-to-use console interface.

## 🛠️ Technologies Used
- Python 3
- Jupyter Notebook
- Dictionaries
- Functions
- Loops and Conditional Statements

## 🧮 Salary Calculation

Net Salary = Basic Salary + Bonus - Deductions

**Example:**
- Basic Salary: ₹40,000
- Bonus: ₹5,000
- Deductions: ₹2,000
- Net Salary: ₹43,000
